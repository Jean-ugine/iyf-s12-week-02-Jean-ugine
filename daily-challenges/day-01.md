# Day 1 — CSS Foundations

## What I practised
- The CSS box model: content, padding, border, and margin.
- The difference between `content-box` and `border-box`.
- Using an external stylesheet to keep CSS separate from HTML.

## What I learned
The `box-sizing` property affects how an element's width is calculated. Using `border-box` includes the padding and border within the declared width, making layouts easier to manage.

## What I will improve
I will practise responsive layouts and check that my pages work on mobile and desktop screens.
