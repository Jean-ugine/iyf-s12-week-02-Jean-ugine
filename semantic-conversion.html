What Is Semantic HTML?

Semantic HTML uses elements that describe the meaning and purpose of content.

Header

The header introduces a page or section.

Navigation

The nav element contains links that help visitors move around a website.

Main Content

The main element contains the page's primary content.

Article and Section

An article is a self-contained piece of content. A section groups related content.

Footer

The footer contains closing information about a page or section.
