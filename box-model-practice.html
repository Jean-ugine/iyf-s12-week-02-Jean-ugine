Understanding the CSS Box Model

Every HTML element is represented as a box. The CSS box model consists of content, padding, border, and margin.

1. Content-box Example

With content-box, the declared width applies to the content. Padding and borders increase the total width.

Content-box

Content width: 200px

Padding: 20px

Border: 5px

2. Border-box Example

With border-box, the declared width includes the content, padding, and border.

Border-box

Total width: 200px

Padding: 20px

Border: 5px

3. Four Parts of the Box Model

The outer layer is margin, followed by border, padding, and the content area in the centre.

Border

4. Layout Debugging Exercise

Imagine a card that should fit inside a 300px-wide container. If its content width is 300px and it also has 20px padding on each side and a 5px border on each side, its total width becomes 350px. This can cause overflow.

Before fixing

Content width: 300px

Padding: 20px per side

Border: 5px per side

To fix the problem, use box-sizing: border-box and max-width: 100% so the card can fit within its container.

After fixing

Maximum width: 300px

Padding and border are included in the width.

What I Learned

  • Content is where text and images appear.
  • Padding creates space inside the border.
  • Border surrounds the padding and content.
  • Margin creates space outside the border.
  • Content-box adds padding and borders to the declared width.
  • Border-box includes padding and borders in the declared width.
  • Max-width can help prevent overflow on smaller screens.
