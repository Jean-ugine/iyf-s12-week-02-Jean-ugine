
# Browser DevTools Exploration

## 1. What Are Developer Tools?

Browser Developer Tools help developers inspect, test, and debug web pages. They include tools for viewing HTML, CSS, JavaScript, network requests, and accessibility information.

## 2. Elements Panel

The Elements panel displays the HTML structure of a webpage and allows developers to inspect elements and test temporary changes.

**My observation:** Open my portfolio, right-click a heading, and select Inspect. Record the heading element you see here.

## 3. Console Panel

The Console displays JavaScript messages, errors, and warnings.

**My observation:** Open the Console and record any errors or warnings found on my page. If there are none, write "No errors or warnings observed."

## 4. Network Panel

The Network panel shows resources requested by a webpage, such as HTML files, images, stylesheets, and scripts.

**My observation:** Reload my portfolio with the Network panel open. Record whether the page and its images load successfully.

## 5. Responsive Design

Responsive testing helps developers check how a webpage behaves at different screen sizes.

**My observation:** Use the device toolbar to test a mobile-sized screen. Record one thing that looks good and one thing that could improve.

## 6. What I Learned

Developer Tools help me understand page structure, identify problems, check resource loading, and test responsive layouts before publishing changes.
